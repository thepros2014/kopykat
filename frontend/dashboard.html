🚀 Quick Start

Make your first API call in 30 seconds. 

# 1. Get your API key from the API Keys tab
# 2. Make a request:

curl -X POST https://YOUR_APP_URL/api/generate \
  -H "Authorization: Bearer sc_YOUR_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "product_description",
    "context": "Describe your product here",
    "tone": "professional",
    "variations": 1
  }'

API Documentation
Everything you need to integrate SnapCopy AI into your application.

Base URL

https://your-app.onrender.com

Authentication

Pass your API key in the Authorization header as a Bearer token. 

Authorization: Bearer sc_your_api_key_here

POST /api/generate

Generate marketing copy.

{
  "type": "product_description",   // required
  "context": "Your product info",  // required (5-2000 chars)
  "tone": "professional",          // optional: professional|casual|urgent|friendly|bold
  "variations": 1,                 // optional: 1-5
  "max_tokens": 300                // optional: 50-1000
}

Copy types: product_description · email_subject · email_body · social_post · ad_headline · ad_body · landing_page_hero · call_to_action · seo_meta_description · blog_intro
