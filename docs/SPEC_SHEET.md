# KopyKat — Technical Spec Sheet

## 🏗 Architecture Overview
KopyKat is a monolithic Python web application serving both a RESTful API and a Server-Side Rendered (SSR) / Static HTML frontend. 

*   **Backend Framework:** FastAPI (Asynchronous Python)
*   **Web Server:** Uvicorn
*   **Database:** PostgreSQL (Hosted on Neon.tech) via SQLAlchemy ORM
*   **AI Engine:** Google Gemini (gemini-flash-latest) via `google-generativeai`
*   **Payments:** Stripe Billing & Webhooks
*   **Task Scheduler:** APScheduler (AsyncIOScheduler) running in the background loop
*   **Frontend:** Vanilla HTML, CSS, JavaScript (No React/Vue overhead)

## 🗄 Database Schema (SQLAlchemy)
1.  **User:** Stores email, hashed password, API keys, subscription tier (`free`, `basic`, `pro`, `business`), and token balances.
2.  **APIKey:** Stores hashed API keys for programmatic access.
3.  **Subscription:** Tracks Stripe customer IDs and subscription status.
4.  **UsageRecord:** Logs every AI generation request (tokens used, endpoint, timestamp).
5.  **RevenueRecord:** Logs every successful Stripe payment for dashboard reporting.
6.  **BlogPost:** Stores SEO-optimized articles generated by the AI.
7.  **DripLog:** Tracks which automated drip emails have been sent to which users (Days 1, 3, 7) to prevent duplicate emails.
8.  **OpportunityLog:** Tracks Reddit post IDs that have already been scouted to prevent duplicate alerts.

## 🔌 API Endpoints
*   `POST /auth/register` - Create account
*   `POST /auth/login` - Get JWT token
*   `POST /api/keys` - Generate a new API Key (starts with `sc_`)
*   `POST /api/generate` - The core AI engine. Accepts `type`, `context`, `tone`. Deducts tokens.
*   `GET /admin/revenue` - Returns total revenue (requires `x-admin-secret` header).
*   `GET /admin/trigger-seo` - Manually kicks off a blog post generation.

## 🤖 Automated Background Tasks (Cron Jobs)
| Task | Frequency | Action |
| :--- | :--- | :--- |
| **Reset Counters** | Daily @ Midnight | Resets daily API limits for users if applicable. |
| **Revenue Report** | Daily @ 8:00 AM | Emails the owner (`OWNER_EMAIL`) a summary of yesterday's revenue. |
| **DB Cleanup** | Sundays @ 3:00 AM | Deletes `UsageRecords` older than 30 days to save DB space. |
| **Subscription Check**| Daily @ 2:00 AM | Audits the database against Stripe to ensure active statuses. |
| **SEO Blog Engine** | Mon, Wed, Fri @ 2:00 PM | Calls Gemini to write an 800-word SEO post and saves it to the DB. |
| **Email Drip Bot** | Daily @ 10:00 AM | Emails free users based on account age (Day 1, 3, 7) to upsell them. |
| **Opportunity Scout** | Every 4 Hours | Scrapes Reddit via API for copywriting leads, drafts replies, and emails the owner. |

## 🚀 Deployment Stack

*   **Environment:** Python 3.11 Docker/Native environment
*   **CI/CD:** Automatic deploys from the `main` branch on GitHub.
