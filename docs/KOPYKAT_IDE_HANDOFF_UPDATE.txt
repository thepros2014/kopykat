============================================================
PROJECT VISION
============================================================
KopyKat is a full-stack e-commerce automation system for small business owners.
It is NOT just an "AI copywriting tool."

The intended product:
  "Give KopyKat your product catalog once.
   It will write, optimize, and distribute your marketing and inventory
   across every platform you sell on — automatically."

Target customer: Solo operators and small business owners running stores
on Shopify, Amazon, eBay, Walmart, Temu, and similar platforms who cannot
afford a full marketing team.

Pricing tiers:
  Boutique   — $97/mo   (250 campaigns)
  Standard   — $297/mo  (1,000 campaigns)
  Megastore  — $897/mo  (5,000 campaigns)

Deployed at: https://kopykat.onrender.com

============================================================
WORKING PRINCIPLES (DO NOT VIOLATE)
============================================================
1. Security first. Reliability first.
2. Surgical code changes — NEVER wholesale-replace a core file.
   Pattern: FETCH current file -> MAKE surgical change -> VERIFY -> COMMIT.
3. Never claim something is fixed or verified when it was not.
4. Small, reversible commits.
5. Never execute arbitrary AI-generated code.
6. Never expose customer credentials to the AI model.
7. Fail closed when authentication, validation, or platform behavior is ambiguous.
8. No emojis in code or HTML — the user has explicitly banned them.
9. Never blindly retry non-idempotent writes.
10. Never report "published/synchronized" unless destination confirms success.
