KOPYKAT ENGINEERING HANDOFF SUMMARY

Purpose
-------
This file is a concise handoff for the current repository snapshot. It
summarizes implemented areas without asserting customer, revenue, benchmark,
or deployment status.

Implemented areas
-----------------
- FastAPI service with authenticated content, campaign, billing, connector,
  inventory, review, pricing, and growth routes.
- Static browser client and React/TypeScript client.
- OpenAI Responses API adapter and Google Gen AI adapter with configured
  provider selection and safe test isolation.
- Encrypted marketplace credentials and BYOK storage.
- Tenant-scoped queries, bounded inputs, security headers, and outbound SSRF
  controls.
- Stripe event signature verification and event idempotency.
- Scheduled internal SEO, email, maintenance, and opportunity-draft jobs.
- Backend, frontend, dependency, and adversarial verification commands
  documented in TEST_READY.md.

Operational boundaries
----------------------
- Provider credentials, Stripe price IDs, managed PostgreSQL, backups,
  monitoring, and incident ownership are deployment responsibilities.
- Generated marketing content requires human review before publication.
- KopyKat does not implement an automated Moltbook visitor, scraper, or
  commercial poster. Review the current Moltbook terms before considering any
  future integration.
